# TutorFind

TutorFind - клиентское веб-приложение для подбора репетиторов и образовательных курсов.

## Основные возможности

- каталог репетиторов и курсов;
- поиск, фильтрация и сортировка;
- добавление в избранное;
- сравнение выбранных вариантов;
- отправка заявок;
- профиль пользователя с историей действий.

## Технологии

HTML, CSS, JavaScript, localStorage.

## Запуск

1. Откройте папку проекта в редакторе.
2. Запустите локальный сервер (например, Live Server).
3. Откройте `index.html` в браузере.
